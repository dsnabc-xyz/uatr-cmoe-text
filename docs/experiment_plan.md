# Experiment Plan

This document tracks the planned DeepShip 4-class ship-radiated noise recognition experiments for `UATRCMoETextResNet18`.

Every experiment must record the exact commit hash:

```bash
git rev-parse HEAD
```

## Baselines

| ID | Model | Loss | Purpose |
|---|---|---|---|
| B0 | ResNet18 | CE | Audio-only backbone baseline |
| B1 | ResNet18 + cMoE | CE | Measure cMoE effect without auxiliary balance |
| B2 | ResNet18 + cMoE | CE + balance | Measure UATR-CMoE balance contribution |
| B3 | UATRCMoETextResNet18 | CE + balance + text_proto_loss | Main method |

## Ablations

### text_proto_weight

```text
[0.01, 0.03, 0.05, 0.1]
```

Goal: measure how strongly frozen text prototypes should guide the audio embedding branch.

### proto_temperature

```text
[0.07, 0.1, 0.5, 1.0]
```

Goal: measure class-prototype logit sharpness. The first default is `0.5`.

### Optional Later Ablations

```text
learnable_temperature: [false, true]
projection_head: linear vs mlp
text_template: class_name vs original vs contrastive vs shuffled
balance_weight: [0.001, 0.003, 0.01, 0.03]
frontend: MelSpectrogram first, CQT later
```

CQT is future work and should not be mixed into the first MelSpectrogram experiments.
